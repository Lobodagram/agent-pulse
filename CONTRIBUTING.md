# Contributing / Участие

Bug reports, documentation corrections and synthetic adapter fixtures are welcome. Read PRIVACY.md and the provider contract before changing an adapter. Each provider needs honest provenance, missing/stale behavior, bounded reads and a fixture test. Never use private session dumps. Run the unit suite; UI work needs actual renders using the public demo fixture. Native client settings must remain unchanged unless a user explicitly configures an opt-in bridge.

The repository uses PolyForm Noncommercial, not MIT/Apache/GPL. Proposed contributions must be original or have clearly documented compatible rights. A pull request does not automatically transfer copyright. Before merging external code, the owner must obtain a written contributor agreement granting sufficient rights to distribute the contribution under this license and separately sublicense it commercially. Until that agreement exists, do not merge third-party contributions. DCO alone does not establish commercial relicensing rights. Contributors retain their copyright unless separately agreed.

Сообщения об ошибках, правки документации и вымышленные тестовые данные приветствуются. Соблюдайте приватность и контракты; нужны тесты пропусков/устаревания и ограниченные чтения. Не прикладывайте переписку или ключи.

Лицензия проекта — PolyForm Noncommercial. Вклад должен быть оригинальным или иметь совместимые подтверждённые права. PR сам по себе не передаёт авторские права. Перед включением чужого кода владелец должен получить письменное соглашение, позволяющее распространять вклад по текущей лицензии и отдельно лицензировать его коммерчески. Без этого соглашения внешний код не сливается; DCO сам по себе недостаточен. Автор сохраняет свои права, если отдельно не согласовано иное.

# Подключение клиентов

[English — полный контракт полей и источники](PROVIDERS.md)

Выбирайте нужных клиентов в настройках. Отключённые адаптеры не опрашиваются. Режим «import» означает только импорт, а не подключение аккаунта. Обновление каждые 5 минут и по кнопке. Дни считаются в UTC; время сброса выводится в местном времени. Даты оплаты всегда вводятся вручную.

## Свои настройки

Python 3.10+ и исходники:

```sh
python3 collector.py catalog
python3 collector.py configure --providers codex,glm,claude --local-patterns off
python3 collector.py subscription --provider codex --kind renewal --date 2027-02-01
python3 collector.py snapshot
```

На Windows команда обычно `python`. Для изолированного тестирования `--state ПУТЬ` указывается **до** подкоманды. В собственной папке данных `config.json` хранит настройки без секретов:

```json
{"enabledProviders":["codex","glm"],"localPatterns":false}
```

Можно явно задать `codexCli`, `nodePath`, `zcodeResources`, `zcodeCli`, `zcodeBuiltin`. Используйте только доверенные установленные исполняемые файлы. Адаптеры ничего не скачивают и не извлекают авторизацию.

## Codex

Установите CLI и авторизуйте его самостоятельно. `codex` должен находиться в PATH; иначе задайте `codexCli`. Используются штатные методы чтения лимитов и токенов; сессии/ходы модели не запускаются. Некоторые версии и тарифы не передают часть методов/полей. Пропуск означает неизвестное значение. Сбросы показываются только при наличии поля от источника.

Анализ событий **выключен по умолчанию**. Включение разрешает ограниченное временное чтение путей недавних событий из штатных метаданных, максимум 30 чатов. Сохраняются числа и категории; локальные токены помечаются частичными и не заменяют историю аккаунта. Статические признаки в обёртке не доказывают исполнение всех команд. Подробности — PRIVACY.md.

## GLM / ZCode

Node из PATH и CLI установленного ZCode запрашивают `usage/stats` за 7 дней в UTC. macOS: `/Applications/ZCode.app/Contents/Resources`. На Windows расположение может отличаться: задайте реальные `zcodeResources` либо `zcodeCli` + `zcodeBuiltin`; при необходимости `nodePath`. Настройки авторизации читает сам клиент; базы напрямую не открываются.

Это история **этого ZCode**, не весь расход GLM на всех устройствах. Ноль локальных сессий не доказывает нулевой глобальный расход. Удалённые лимиты подписки здесь не подключены. Даты оплаты/«без подписки» задаются вручную.

## Claude Code: мост status-line

Автоматических правок настроек нет. Сохраните старую настройку status-line и явно укажите команду запуска скрипта из исходников:

```json
{"statusLine":{"type":"command","command":"python3 /absolute/path/to/agent-pulse/scripts/claude_statusline.py"}}
```

Используйте свои абсолютные пути; на Windows подходящий Python и кавычки вокруг путей с пробелами. Эта настройка заменяет прежнюю команду status-line. Если требуется сохранить её вывод, объедините скрипты самостоятельно.

Из штатного JSON на stdin мост сохраняет только разрешённые счётчики в собственный `imports/claude.json`. Через 10 минут без события — отметка устаревания. Перезапустите/обновите виджет.

Лимиты `five_hour`/`seven_day` зависят от тарифа и могут появиться только после первого ответа штатного клиента; Agent Pulse этот ответ **не запускает**. Сумма `context_window.total_input_tokens` и `total_output_tokens` — **размер текущего контекста**, не накопленный расход. Названия/ID сессий, пути переписки, cwd и промпты отбрасываются. Реальный аккаунт пока не проверен.

## Kimi Code: экспериментальное чтение квот

Включите Kimi и создайте приватный `Secrets.json` в собственной папке данных:

```json
{"kimi":{"api_key":"YOUR_OWN_KIMI_CODE_KEY"}}
```

Подставьте собственный ключ через штатный процесс поставщика. На POSIX режим 600; на Windows ограничьте NTFS-доступ своим пользователем. Не публикуйте файл/ключ.

Используется GET официального клиента `https://api.kimi.com/coding/v1/usages`, без переадресаций и прокси окружения. Изменение схемы/ошибка даёт «нет данных». Единицы квоты не превращаются в расход токенов. Контракт экспериментальный, тестовые данные проверены, живой аккаунт — пока нет.

## Qwen Code: уже запущенный loopback

Если штатный локальный Qwen-сервер уже запущен, задайте в `config.json` `qwenBaseUrl` с его реальным origin, например `http://127.0.0.1:PORT`. Виджет не угадывает порт и не запускает сервер.

Принимается только HTTP loopback `127.0.0.1`/`::1`, без авторизации в URL, пути, query и fragment. Читается `/usage/dashboard?range=today&heatmapDays=30`. Сохраняются агрегаты токенов по дням и безопасные имена skills. Файлы переписки не открываются. API квот подписки здесь нет. Контракт проверен на тестовых данных; реальное подключение пока не проверено.

## Остальные: локальный импорт

Gemini, Cursor, Copilot, Windsurf, DeepSeek и OpenRouter — **только импорт**. Счётчики выгружаете вы. Чтения cookies, скрытых API или хранилищ ключей нет. Данные импорта не выдаются за проверенный отчёт аккаунта.

```sh
python3 collector.py ingest --provider cursor --file /path/to/counters.json
```

Схема — `examples/import.json`; поля и полный пример приведены в английском руководстве. `observedAt` — реальное время наблюдения в секундах epoch. Укажите только подтверждённые числа. Пропуски не заменяйте нулями; стоимость, контекст и квоты не пересчитывайте в токены. Неизвестные поля отбрасываются; числа конечные и неотрицательные, boolean запрещён. Импорт ограничен 2 MiB; старые, будущие или недатированные данные помечаются устаревшими. Claude-импорт отбрасывает поля расхода, чтобы контекст не стал расходом.

## Если данные не появились

Проверьте режим поддержки, установку/авторизацию клиента, runtime-пути и обновите. Недоступность не означает нулевой расход. Лимиты могут работать без счётчиков токенов. Старые значения помечаются, предыдущий день не становится сегодняшним расходом. Дата сброса не равна продлению. Повторы — материал для человеческой проверки, не повод автоматически ставить инструменты.

Первичные источники всех контрактов: разделы Codex, ZCode, Claude, Kimi и Qwen в [английском руководстве](PROVIDERS.md).

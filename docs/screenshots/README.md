# Screenshot provenance / происхождение снимков

All images use invented, DEMO-labelled account/workflow data. They demonstrate the interface, not actual productivity, accepted tasks or subscription savings. No personal account or conversation screenshot belongs here.

The following gallery files were refreshed from the current **0.14.6/build47** Mac executable on 2026-10-16 and visually reviewed:

- `widget-en.png`, `widget-ru.png`: compact current widget with collapsed benefit rows.
- `widget-small-en.png`, `widget-small-ru.png`: byte-identical copies of the corresponding compact captures.
- `benefit-en.png`, `benefit-ru.png`: five-row activity/improvement/effect/cache separation; no selected effect evaluation.
- `settings-active-en.png`, `settings-ru.png`: current Settings viewport; the page scrolls to additional controls. Demo mode does not change login items.

Other captures illustrate screens whose presentation is unchanged; their dated original validation is preserved in [QA](../QA.md). Image hashes in `manifest.json` are required by the public export gate. Runtime/fixture assertions and human visual review are separate checks.

Все данные вымышлены. Восемь перечисленных файлов актуализированы по версии 0.14.6; шесть разных снимков просмотрены, два малых — точные копии. Остальные снимки оставлены для неизменившихся экранов с исходной датированной проверкой в QA. Настройки представлены в пределах видимой прокручиваемой области, а не как вся форма целиком.

# Контракты доказательств в 0.5.0

[English](EVIDENCE.md)

«Навыки» различает чтение точного зарегистрированного файла скилла, успешный явный вызов Skill/инструмента/MCP и ручную отметку сессии. Чтение не доказывает выполнение инструкций; отсутствие наблюдения не доказывает неиспользование. Сохраняются только проверенные названия. Необязательный `locator` каталога — абсолютный путь файла — сразу превращается в HMAC и буквально не хранится. Сканирование не читает инструкции. Неизвестные и ошибочные вызовы не подтверждают успешное использование.

Ручная отметка: `python3 collector.py journal --action declare --provider codex --session HASH --capability REVIEWED_ID --kind skill`. Сессия и запись каталога должны существовать. Отметка не выдаётся за штатный вызов.

Источники результата: штатный сбой, структурированный exit code, завершение несистемного инструмента, отсутствие exit code, продолжающийся процесс. Текст stdout, даже «Exit code: 0», не подтверждает успех shell. Противоречивые окончания дают неизвестный результат и отменяют автоматическое доказательство применения навыка. Поздний корректный exit code может уточнить неизвестный результат. Пропущенный конец после границы сессии — пробел сбора, не ошибка команды. Без границы незавершённый вызов устаревает через десять минут.

Известные составные команды разбираются ограниченно, без исполнения. Остаются только очищенные семейства операций и операторы; подстановки, неподдерживаемый синтаксис и неизвестные команды не классифицируются. Это не анализ смысла кода и не доказательство исполнения каждой ветки. Сценарии различают семейства команд и разрываются при параллельности, сбое, продолжающемся процессе, неправильном времени и пропущенном окончании.

Кандидат между клиентами требует общего известного HMAC проекта, одинакового семейства, двух провайдеров, трёх ходов и шести вызовов. Совпадение формы не доказывает одинаковую задачу.

Пакет проверки: `python3 collector.py journal --action evidence --finding FINDING_ID --file /private/evidence.json`. Аналогичный локальный MCP — `pulse_evidence`. Пакет содержит ограниченные доказательства текущего паттерна и шаги проверки охвата, задачи, существующих инструментов и качества перед созданием скрипта/скилла/MCP. Автоматической установки или исполнения нет. Точная цена каждого вызова и гарантированная экономия не заявляются.

`python3 scripts/analytics_benchmark.py` проверяет 14 размеченных выдуманных примеров во временных журналах, без моделей и реальных данных. Пять ожидаемых положительных типов находок, ноль ложных и пропущенных — результат только этих примеров. Это не точность на реальной работе и не измеренная экономия.

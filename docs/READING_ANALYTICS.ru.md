# Как читать аналитику

[English](READING_ANALYTICS.md)

Счётчики квот и токенов не доказывают охват событий инструментов. Вкладки отвечают на разные вопросы:

| Вкладка | Источник | Что означает пустое значение |
| --- | --- | --- |
| Обзор | Штатные usage-счётчики, история агрегатов, охват журнала | Непереданные токены неизвестны. Сброс лимита не означает продление подписки. |
| Сценарии | Полученные вызовы и осторожные пороги повторений | Вызовы могут быть записаны без подходящего сценария. Нет находок — не значит выключен наблюдатель. |
| Сессии | Начала/завершения инструментов и штатные поля модели | Пропуск завершения/результата/модели остаётся незавершённым или неизвестным. Назад/Далее продолжает длинные сессии. |
| Навыки | Проверенный каталог, поддерживаемые подтверждения, частоты инструментов | Нет подтверждённых событий — не доказательство неиспользования. Инструменты идут первыми; на Mac раскрываются записи без наблюдений. |
| Сравнение | Ручные метки задач, вариантов, приёмки | Пустые группы означают недостаток проверенных данных. Минимум три сессии на вариант; сопоставимость сложности/моделей проверяет человек. |

Время охвата показывает последний полученный вызов. Тишина может означать простой клиента. Отношение пар к вызовам относится только к полученным событиям: общее число невидимых действий неизвестно. Отклонения — суммарный зарегистрированный счётчик, а не измерение всех потерь.

## Ограничения распознавания

Список находок отдаёт приоритет повторным сбоям, чтениям и одинаковым запросам перед общими цепочками категорий. Обновления списка задач, плана, ожидания и запросы уточнений остаются в журнале, но не порождают рекомендации автоматизации и разрывают цепочки. Это не удаление событий и не доказательство потери времени.

Сводка показывает число распознанных семейств, неизвестных и служебных операций. Имена поддерживаемых команд checksum/archive/plist/HTTP, GitHub CI и помощников mesh/release/context уточняют категории; имя команды не подтверждает её происхождение, успешность или доступность MCP. Для старых записей можно уточнить известное имя инструмента, но неизвестные shell-аргументы не восстанавливаются. После изменения классификации используйте свежий ID находки; исчезновение прежней карточки не доказывает исправление сценария.

Распознаётся точный зарегистрированный путь в Read/read_file/cat_file, явное имя в Skill/use_skill и совпадающее зарегистрированное пространство MCP. С 0.7.0 успешные строгие буквальные cat/sed/head/tail сопоставляются с зарегистрированными путями, без подстановок или восстановления истории. Пространства MCP вне каталога видны отдельно и среди инструментов; это не доказательство плагина или доступности сервера. Чтение скилла не доказывает применение инструкций. Нельзя удалять навык из-за неподтверждённого применения.

## Продолжение длинной сессии

На Mac/Windows страницы по 500 вызовов. MCP по умолчанию возвращает 50, допускает 1–100. Подписанный локальный курсор продолжает или повторно читает тот же снимок. Промпты, аргументы и результаты не включаются. Сводка моделей относится ко всему ограниченному снимку, вызовы — к текущей странице.

```sh
agent-pulse journal --action session --session HASHED_SESSION_ID --limit 100
agent-pulse journal --action session --session HASHED_SESSION_ID --limit 100 --cursor RETURNED_NEXT_CURSOR --file page.json
```

cursor повторно читает страницу, nextCursor продолжает. Файл содержит одну страницу, не автоматический экспорт всей истории. Без установки используйте python3 collector.py либо готовый helper. MCP pulse_session принимает sessionId, необязательные cursor и limit.

Новые события после первого чтения не включаются. Изменение прежних данных — позднее завершение, уточнение/конфликт модели, удаление по сроку хранения — отклоняет продолжение. Откройте сессию заново. Ограничения: 30 дней и 100 000 сохраняемых полученных событий, достижение лимита отмечено явно. Неполученные события не восстанавливаются. recentCalls общего отчёта/экспорта — список из 100 вызовов, не вся история.

Панель Mac чередует полные названия клиентов в верхнем регистре без номера страницы. Компактные строки Windows используют такие же названия; длина штатной подсказки трея ограничена.

## Дневная детализация токенов

Mac: «Токены»; Windows: «Токены по дням». График Mac использует понятные единицы вместо научной записи. Наведение показывает день UTC, нажатие закрепляет его; список дат доступен без указателя. Для каждого включённого клиента видны точные счётчики и охват; отсутствие записи означает неизвестное значение. Эти дневные источники не передают почасовые счётчики. При восстановлении отставания локального Codex старые непрочитанные байты пропускаются в пределах ограниченного чтения; накопительная база сбрасывается, чтобы старый расход не приписывался сегодняшнему дню. Пропуск обозначается предупреждением источника. Переданный счётчик аккаунта имеет приоритет над перекрывающимися локальными данными.

# Как читать аналитику

[English](READING_ANALYTICS.md)

Счётчики квот и токенов не доказывают охват событий инструментов. Вкладки отвечают на разные вопросы:

| Вкладка | Источник | Что означает пустое значение |
| --- | --- | --- |
| Обзор | Штатные usage-счётчики, история агрегатов, охват журнала | Непереданные токены неизвестны. Сброс лимита не означает продление подписки. |
| Сценарии | Полученные вызовы и осторожные пороги повторений | Вызовы могут быть записаны без подходящего сценария. Нет находок — не значит выключен наблюдатель. |
| Сессии | Начала/завершения инструментов и штатные поля модели | Пропуск завершения/результата/модели остаётся незавершённым или неизвестным. Назад/Далее продолжает длинные сессии. |
| Навыки | Проверенный каталог, поддерживаемые подтверждения, частоты инструментов | Нет подтверждённых событий — не доказательство неиспользования. Инструменты идут первыми; на Mac раскрываются записи без наблюдений. |
| Сравнение | Ручные метки задач, вариантов, приёмки | Пустые группы означают недостаток проверенных данных. Минимум три сессии на вариант; сопоставимость сложности/моделей проверяет человек. |

Время охвата показывает последний полученный вызов. Тишина может означать простой клиента. Отношение пар к вызовам относится только к полученным событиям: общее число невидимых действий неизвестно. Отклонения — суммарный зарегистрированный счётчик, а не измерение всех потерь.

## Ограничения распознавания

Распознаётся точный зарегистрированный путь в Read/read_file/cat_file, явное имя в Skill/use_skill и совпадающее зарегистрированное пространство MCP. Чтение cat/sed через shell не привязывается к скиллу. MCP вне каталога виден среди инструментов. Чтение скилла не доказывает применение инструкций. Нельзя удалять навык из-за неподтверждённого применения.

## Продолжение длинной сессии

На Mac/Windows страницы по 500 вызовов. MCP по умолчанию возвращает 50, допускает 1–100. Подписанный локальный курсор продолжает или повторно читает тот же снимок. Промпты, аргументы и результаты не включаются. Сводка моделей относится ко всему ограниченному снимку, вызовы — к текущей странице.

```sh
agent-pulse journal --action session --session HASHED_SESSION_ID --limit 100
agent-pulse journal --action session --session HASHED_SESSION_ID --limit 100 --cursor RETURNED_NEXT_CURSOR --file page.json
```

cursor повторно читает страницу, nextCursor продолжает. Файл содержит одну страницу, не автоматический экспорт всей истории. Без установки используйте python3 collector.py либо готовый helper. MCP pulse_session принимает sessionId, необязательные cursor и limit.

Новые события после первого чтения не включаются. Изменение прежних данных — позднее завершение, уточнение/конфликт модели, удаление по сроку хранения — отклоняет продолжение. Откройте сессию заново. Ограничения: 30 дней и 20 000 полученных событий, достижение лимита отмечено явно. Неполученные события не восстанавливаются. recentCalls общего отчёта/экспорта — список из 100 вызовов, не вся история.

Панель Mac чередует полные названия клиентов в верхнем регистре без номера страницы. Компактные строки Windows используют такие же названия; длина штатной подсказки трея ограничена.

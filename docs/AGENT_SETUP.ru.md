# Настройка и управление через агента

Пришлите агенту ссылку на репозиторий и попросите: «Прочитай docs/AGENT_SETUP.ru.md, проверь мою установку Agent Pulse, настрой нужных клиентов без раскрытия ключей и объясни полноту сбора». Это локальные инструменты, а не постоянная панель внутри чата. Сам Agent Pulse модели не вызывает; работа агента по вашему запросу расходует его обычную подписку.

## Два переносимых навыка

Скачайте проверенные исходники релиза. Из этой папки выполните Python 3.11+:

```sh
python scripts/install_agent_skills.py --destination ~/.agents/skills
```

Codex обнаруживает навыки в этой пользовательской папке. Для ZCode укажите `~/.zcode/skills`; для другого клиента — его документированную папку или предложите прочитать SKILL.md вручную. Установщик сохраняет существующие навыки, отказывается перезаписывать совпадающие имена и переходить по симлинкам. Он не меняет конфиги MCP и не запускает агента. Навыки выбираются по задаче; перечитайте их штатным способом клиента.

## CLI и локальный MCP

В отдельном venv команда `python -m pip install .` устанавливает `agent-pulse` и `agent-pulse-mcp`. Можно пользоваться `python collector.py` из исходников или упакованным `pulse-collector`: на Mac внутри приложения Contents/Resources, на Windows рядом с AgentPulse.exe. В конфигурациях клиентов используйте абсолютные пути.

```sh
agent-pulse catalog
agent-pulse settings
agent-pulse journal --format markdown --language ru
codex mcp add agent-pulse -- agent-pulse-mcp
```

По умолчанию доступны только чтения: pulse_report, pulse_session, pulse_evidence, pulse_compare, pulse_review_pack, pulse_settings. В ZCode добавьте STDIO-сервер через настройки MCP: команда — абсолютный путь к agent-pulse-mcp, аргументы — пустой массив. Его родной конфиг использует mcp.servers. Формат `.agents/mcp.json` с mcpServers — запасной; при наличии родных серверов того же уровня он пропускается. Сохраняйте прежние подключения. Claude, Kimi и другие MCP-клиенты могут подключить тот же STDIO-процесс через свои штатные настройки; подтверждайте реальный список инструментов.

## Управление по выбору

При явном запросе владельца используйте `agent-pulse-mcp --allow-control`, для упакованного обработчика — `pulse-collector mcp --allow-control`. Четыре дополнительных инструмента меняют ограниченные настройки, ручные даты подписок, решения по находкам и метки сессий. Они не принимают ключи, пути экспорта, произвольные команды и не устанавливают хуки.

pulse_configure принимает changes. Поля: enabledProviders, localPatterns, localTokens, language (en/ru), widgetScale (0.8–1), displayMode (floating/menu/compact/tray), metricMode (limits/today), topmost, menuNumbers, menuFollowActive. На Mac compact/tray означают строку меню; Windows преобразует menu в tray. Флаги меню относятся к macOS. Изменения внешнего вида проверяются примерно каждые пять секунд; показатели клиентов обновляются по обычному расписанию или вручную.

```sh
printf '%s' '{"enabledProviders":["codex","glm"],"metricMode":"limits","widgetScale":0.8}' | agent-pulse settings --update
agent-pulse settings
```

Дату оплаты указывайте со слов владельца; сброс квоты — другая дата. Ключ GLM вводится в защищённое поле приложения; ключи других адаптеров — по их локальной инструкции. Не передавайте их в чат или аргументы команды. pulse_settings исключает неизвестные поля конфига и ключи; диагностика ошибок использует фиксированные категории.

## Сбор и полезность

Наблюдатель подключается отдельно и по запросу: `agent-pulse hooks --provider codex --action install`, также glm/claude. Обратное действие — remove. Чужие хуки сохраняются; штатное доверие клиента нельзя обходить. MCP не меняет эти настройки и не запускает сессии.

Проверяйте реальные последующие вызовы, пары событий, пропуски и неизвестные исходы. Ноль находок может означать недостигнутый порог; отсутствующие показатели не равны нулю. Тестовые события держите в отдельном `--state`. Прежде чем отметить находку выполненной или задачу принятой, требуется реальное изменение и проверенный результат. Следуйте [циклу улучшения](IMPROVEMENT_LOOP.ru.md). Ручные настройки и аналитика доступны без навыков/MCP.

Проверено 07.10.2026: [Codex навыки](https://developers.openai.com/codex/skills), [Codex MCP](https://developers.openai.com/codex/mcp), [ZCode навыки](https://zcode.z.ai/en/docs/skill), [ZCode MCP](https://zcode.z.ai/en/docs/mcp-services). Поддержка каждым сторонним клиентом зависит от его версии; универсальная сертификация не заявляется.

## Одновременная настройка

Встроенные UI, CLI и MCP записывают только изменённые поля под общей межпроцессной блокировкой, атомарно заменяют файл и увеличивают `configRevision`. Номер возвращается при чтении и успешной настройке. Разные поля сохраняются вместе; для одного поля побеждает последняя завершённая запись. Диалога конфликтов и гарантии compare-and-swap нет. Открытый выбор клиентов — черновик: «Применить» заменяет всю эту группу. При занятом файле запись прекращается через секунду без изменения конфига; повторите после завершения другой операции. Не редактируйте config.json напрямую во время работы приложения.

Mac и Windows проверяют визуальные настройки примерно каждые пять секунд; снапшоты и состав клиентов обновляются отдельно. Все открытые формы мгновенно не синхронизируются. `pulse_settings` не создаёт отсутствующую папку или базу, не инициализирует схему и не выполняет миграции.

Agent Pulse 0.9.0 — agent setup and bounded local control / навыки и локальное управление

Two portable skills help agents set up the app and analyze workflow evidence. Follow docs/AGENT_SETUP.md or .ru.md; the installer requires an explicit destination and preserves existing skills. The local stdio MCP has six read-only tools by default. Explicit --allow-control adds four bounded tools for preferences, manual billing dates, finding decisions and session annotations. No credential input, arbitrary shell execution, native hook edits or model calls. Third-party client connection/discovery must be verified in that client.

Visual settings synchronize locally; fixture language no longer changes saved preferences. GLM key paste trims outer whitespace, and failed quota reads expose fixed diagnostic categories without response/key data. Packaged Windows TLS is verified with a no-key HTTPS diagnostic; certificate and hostname checks remain required. Screenshots use only synthetic fixtures and current full provider names.

New versions are AGPL-3.0-only. Commercial use and sale are allowed under AGPL obligations; earlier published MIT grants remain valid. Separate commercial terms require an agreement with the actual rights holder. No retroactive removal of MIT permissions.

# Agent Pulse0.10.4 — logo / логотип

The supplied orange Agent Pulse logo now identifies the macOS application, widget and utility windows; Windows executable, tray and windows; and repository README/social preview. The original macOS menu-bar symbol is retained at the owner’s request. Native icon resources are bundled, including frozen Windows resource paths. Approved image hashes/formats are checked by the public exporter.

Присланный логотип добавлен в иконки Mac/Windows, виджет, окна и материалы GitHub. Автозапуск остаётся доступным через галочку; для включения после входа она должна быть отмечена. На компьютере владельца включение проверяется отдельно от демонстрационных сценариев.

Source/platform/package/installed results are recorded in [QA](QA.md) after their checks complete. macOS/Windows packages remain a public preview. Startup register/enable and app-relaunch checks do not substitute for an actual reboot. Physical Windows, Mac Spaces/multi-display, live Kimi and signing/notarization retain their existing limitations. No model calls or private activity are published.

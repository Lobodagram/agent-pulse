## Agent Pulse 0.2.1 — public preview

A local always-on-top dashboard for coding-agent quotas, reported tokens, reset times, manual billing dates and recurring tool categories.

English/Russian UI and documentation. macOS native widget; Windows x64 preview. Selectable Codex, GLM/ZCode, Claude, Kimi, Qwen and import-only clients; see the README support matrix. Claude context size is not token spend. Local Codex event projection is off by default. No model calls or telemetry uploads.

Packages: macOS ARM64/Intel and Windows x64 built in Actions, with SHA256SUMS. macOS is ad-hoc signed, not notarized; Windows is unsigned. Preview adapters and interactive Windows behavior still require real-device/account acceptance beyond automated tests. Do not assume all clients expose subscription/billing analytics.

Free noncommercial use under PolyForm Noncommercial 1.0.0; commercial use requires a separately purchased written license from Lobodagram. This is source-available, not OSI open source.

## Публичная предварительная версия

Локальный виджет поверх окон: лимиты, переданные токены, даты сброса, ручные даты подписок и повторяющиеся категории инструментов.

Русский/английский интерфейс и инструкции. macOS — нативный виджет, Windows x64 — preview. Клиенты и реальный охват указаны в README: часть автоматическая, часть через мост/API, часть только импорт. Контекст Claude не считается расходом. Локальный анализ событий Codex выключен по умолчанию. Модели не вызываются, телеметрия не выгружается.

Сборки macOS ARM64/Intel и Windows x64 выполняются в Actions; рядом SHA256SUMS. Нотариализации Apple и Windows-подписи нет. Живые аккаунты экспериментальных адаптеров и интерактивное поведение Windows ещё требуют ручной приёмки.

Некоммерческое применение бесплатно по PolyForm Noncommercial 1.0.0. Коммерческое — по отдельной приобретённой письменной лицензии владельца Lobodagram.

# Agent Pulse contributor instructions

Read README.md, PRIVACY.md, docs/PROVIDERS.md and docs/AGENT_SETUP.md. The portable skills in agent-skills support setup and evidence review. Local MCP is read-only unless the owner explicitly enables --allow-control; do not fabricate review decisions. Keep native clients read-only. Never call models, scrape credentials, start sessions or upload telemetry. Preserve unknown values and source/coverage labels. Run `python -m unittest discover -s tests -v`. UI screenshots must use `examples/demo.json`; never publish account or conversation data. No company rules, private home paths or runtime state belongs in this repository. AGPL-3.0-only contributor rights are described in CONTRIBUTING.md.
